## 提案事項
- **採用**: 全体コメントを各領収書へ同じ値で保存し、グループ代替として利用
- **採用**: 個別メモ履歴は重複を除いて最新10件程度を表示
- **採用**: Web Share APIは1回の共有で本文と複数画像を渡す
- **不採用**: Web Share APIの複数回自動発火による「本文→画像→本文→画像」
  - OS・LINE側の共有処理を制御できず、共有中エラーやユーザー操作制限があるため

## 技術的メモ
- Web Share APIの`ShareData`は本文と複数ファイルを渡せるが、LINE側での配置順は保証されない
- 個別メモは空欄を除外し、選択順を維持するため「◯枚目メモ」形式を採用
- Safari/WebKitではIndexedDBから取得したBlobハンドルが画像表示時に不安定になる場合がある
- `arrayBuffer()`で読み出し、新しいBlobを生成すると画像表示を安定化できる
- GitHub Pagesの公開バージョンは、デプロイ対象コミットの短縮IDとして表示
- PWAの本番ビルド前に`dist`を安全にクリーンアップ
- `npm run build`、`npm run lint`ともに成功
